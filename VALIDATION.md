# Отчёт о доработке и ограничениях

- Изменены CSV, лимит входа по пользователю/IP, заголовки, отключение документации, retention, минимальная оценка без LLM, доказательства, параметры Whisper, стерео с заданным каналом, оценочная пауза для моно, API поиска и пагинации, пакетная загрузка, карточка и плеер, тренды и рейтинг, тайм-аут LLM, частичная сверка зависших заданий, сеть, имена образов и CI.
- Проверено: 3 теста правил; компиляция Python. Полная регрессия не выполнена: нет redis/av/RQ и других зависимостей, установка недоступна по сети. npm ci не завершился, сборка остановилась на отсутствующих типах. Docker отсутствует. Образы и сетевое поведение не проверены. CI и интеграционная проверка подключений добавлены, не запускались. Нужна проверка автоповторов и конкурентного восстановления на реальном RQ. Не все инфраструктурные контейнеры переведены на non-root.
- Не выполнено: замер 10 минут на ноутбуке, WER, Playwright, 10–15 размеченных аудио, подтверждённая тональность/полнота/решение проблемы, кнопка проверки изоляции, разбиение всех frontend компонентов. Не утверждается полное соответствие ТЗ. Моно-пауза — прокси, стерео требует явно заданного канала. Правила ограничены несколькими фразами и требуют проверки человеком. Процент отражает один стоп-критерий из четырёх, не банковский KPI. Неизвестные значения не выдуманы.
- Проверить при переносе: права тома хранения, наличие образов и моделей, доступность frontend через bridge, миграции, реальную авторизацию и защиту proxy-заголовков. Новый storage том требует переноса старых файлов вручную. Не заменяйте рабочее развёртывание без резервной копии.
