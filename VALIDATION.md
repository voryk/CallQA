# Проверка доработок

Основа: CallQA-feature-rachik(5).zip (a0505a51c9097039e7811bcebe52a603343adc01).

- 11 тестов `tests/test_enhancements.py` прошли в доступной среде: текстовые роли, акустические признаки и неоднозначность, тональность, время ответа, интервалы статистики, фильтр SQL, передача ролей и проверка цитат, URL PostgreSQL.
- Python компилируется; TSX транслируется встроенным TypeScript без синтаксических ошибок; YAML Compose читается.
- Полный `pytest` заблокирован отсутствующей библиотекой redis; Docker недоступен; `npm ci --offline` заблокирован отсутствующим кешем Vite. Полная сборка и end-to-end не подтверждены.
- Миграции исходной ветки оставлены без изменений. Новые признаки сохраняются в существующих JSON-полях.
- Новая установка по умолчанию использует проект `callguard-rachik5`, порты 5174 и 8001, отдельные тома. Конфликт с произвольной другой программой на этих портах всё ещё возможен; порты меняются в `.env`.
- Для испытания используйте локальную Whisper и Qwen. Qwen требуется для полной оценки, но её готовность не блокирует STT. Оценка ролей приблизительна: не идентификация по голосу, не подтверждённая диаризация; громкость записанного сигнала не является физическим SPL. Неопределённые реплики не назначаются принудительно. Раздельная тональность основана на тексте, не на распознавании эмоций по голосу.
- В этой версии нет новых замеров обработки 10-минутного разговора; требуется проверка на целевой машине.
