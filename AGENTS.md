# AGENTS.md — правила для Codex и других агентов

Источник требований: `PROJECT_PLAN_CallGuard_AI.md`. Читать перед началом работы.

1. Сначала составь перечень реализованного и недостающего, затем реализуй P0 по модулям.
2. Сохраняй совместимость API и миграций. Схема БД меняется только через Alembic.
3. Не объявляй функцию готовой без теста. Показывай изменённые файлы, команды запуска, результаты тестов и риски.
4. Offline-first: никаких внешних AI API; аудио и транскрипты не уходят за пределы локальной инфраструктуры.
5. Каждый вывод оценки имеет критерий, цитату и таймкод либо статус «недостаточно данных». Вероятность не выдавать за факт.
6. Не подменять обработку заранее записанными результатами без явной маркировки «демо».
7. Зоны владения указаны в `TEAM_PLAN.md`; чужие файлы меняй только через согласованный PR.
8. Секреты и реальные данные клиентов в Git не добавлять.
