# Передача CallGuard AI на банковский пилот

## Исторические результаты исходной ветки (17 ноября 2026 года)

Эти результаты перенесены из исходного архива и не являются подтверждением запуска новой сборки.

- Docker Compose собирает и запускает frontend, API, worker, retention, PostgreSQL, Redis и Ollama.
- `GET /health/ready` возвращает 200 при доступной базе, очереди и локальной модели Whisper.
- 8 backend тестов проходят; frontend собирается TypeScript/Vite.
- Тестовый MP3 прошёл через API, RQ и PostgreSQL: сохранена русская расшифровка. Qwen2.5:3b проверена локальным запросом; при недоступности модели оценка получает отдельный статус `failed`, расшифровка сохраняется.
- Авторизация закрывает API без сессии; роли, аудит, 30-дневное удаление и ручное подтверждение оценки проверены тестами.

## Обязательные решения банка перед реальными данными

| Область | Нужное решение | Текущее состояние |
| --- | --- | --- |
| Вход сотрудников | Название внутреннего IdP, протокол OIDC/LDAP/AD, группы и роли | Локальные учётные записи |
| Сеть и TLS | Внутренний DNS, сертификат, обратный прокси, правила доступа | Только loopback HTTP |
| Секреты | Хранилище секретов и ротация паролей | Локальный `.env` |
| Хранение | Шифрование диска, резервных копий, правила восстановления и удаления копий | Локальный том, срок 30 дней |
| Аудит | Выгрузка в SIEM, защита от изменения, срок хранения | Таблица `audit_events` |
| Качество | Размеченная выборка, допустимые ошибки STT и KPI, утверждённый скрипт оценки | Whisper tiny для теста, Qwen установлена только на текущей машине |
| Производительность | Целевой сервер, поток звонков, требуемое время обработки | Не измерено на 10-минутных звонках |
| Среднее время ответа | Правило вычисления и разделение говорящих | Оценочный показатель по переходам между ролями, после ручного подтверждения |

До закрытия этих пунктов система должна использоваться только с тестовыми записями. Пилот с реальными клиентскими данными требует согласования с ИБ и владельцем процесса банка.
